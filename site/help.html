imgx 1.0.0

Help output

This is exactly what imgx --help prints.

imgx --help 
imgx - convert images from the terminal

Usage
  imgx <input...> [options]

  Inputs are files, directories (walked recursively) or globs.
  Without --out, files are written next to their source as png.

Options
  -o, --out <path>       Output file, or directory (created if missing,
                         with the input folder structure mirrored inside)
  -f, --format <fmt>     png | jpeg | webp | avif | tiff      [default: png]
  -w, --width <px>       Target width. SVGs render at exactly this size,
                         raster images are only ever shrunk
      --height <px>      Target height, ignored when --width is set
  -s, --scale <n>        SVG only: render at n times its intrinsic size
  -q, --quality <1-100>  Quality for jpeg, webp and avif       [default: 85]
      --background <css> Color behind JPEG transparency      [default: white]
                         #rrggbb, #rgb, rgb(r,g,b), or a name:
                         white black grey gray red green blue
      --overwrite        Replace existing files instead of skipping them
      --dry-run          Print what would be written, change nothing
  -h, --help             Show this help
      --version          Show the version

Formats
  reads   svg png jpg jpeg webp avif tif tiff gif bmp ico tga pnm,
          plus heic heif psd pdf and camera raw through macOS sips
  writes  png jpeg webp avif tiff

  Rasters are never enlarged. Animated gif and webp use their first
  frame. There is no svg output: rasterizing a photo to vectors never
  returns the original curves.

Behavior
  A --out path ending in an image extension names the output file;
  anything else is a directory and gets created. Existing files are
  skipped, never replaced, unless --overwrite is given. The exit status
  is 1 if any file fails.

Examples
  imgx diagram.svg -w 2400
  imgx hero.webp -f png -o images/
  imgx screenshots/ -f webp -q 90 -o build/webp
  imgx "shots/*.png" -w 1280 -o resized
  imgx photo.heic -f jpeg -q 95 -o print/

Full manual: man imgx

Options

FlagDefaultWhat it does
-o --out <path> next to the source A path ending in an image extension names a single output file. Anything else is a directory, created if missing, with the input folder structure mirrored inside it. Must be a directory when converting more than one file.
-f --format <fmt> png One of png, jpeg, webp, avif, tiff. Inferred from the extension of --out when that is given.
-w --width <px> source width Target width. SVGs are rasterized at exactly this width. Rasters are only ever shrunk; a width at or above the source width is ignored.
--height <px> source height Target height, preserving aspect ratio. Ignored when --width is also given.
-s --scale <n> 1 SVG only. Render at n times the intrinsic size. -s 2 gives a retina export.
-q --quality <1-100> 85 Encoder quality for jpeg, webp and avif. Ignored for the lossless formats. 100 is the best a lossy codec offers, not a lossless mode.
--background <css> #ffffff The colour used to fill transparent pixels when writing JPEG, which has no alpha channel. Accepts #rrggbb, #rgb, rgb(r,g,b) or a name. An unrecognised colour is an error, not a silent fallback.
--overwrite off Replace destination files that already exist. Without it an existing file is skipped.
--dry-run off Resolve inputs, outputs and formats, print what would be written, and exit without touching the filesystem.
-h --help — Print usage to standard output and exit 0.
--version — Print the version and exit 0.

Where files land

--out is a directory unless it ends in an image extension. -o build/, -o build and -o logo.png all do the obvious thing. Directories are created, including missing parents. When the input is a directory, the folder structure inside it is mirrored under --out: 

imgx shots/ -o build
# shots/a.png   -> build/a.png
# shots/v2/b.svg -> build/v2/b.png

If both -f and an -o file extension are given and they disagree, that is an error rather than a silently renamed file.

Formats

One row per format. Everything in the Read column is a valid input; only the formats marked in Write can be an output.

Format Extension Read Write Notes
svg .svg yes no Rasterized with resvg, so -w and -s produce genuinely sharp vectors at any size.
png .png yes yes Lossless, keeps transparency. The default output.
jpeg .jpg yes yes Lossy. Transparency is flattened onto --background.
webp .webp yes yes Lossy, keeps transparency, much smaller than PNG.
avif .avif yes yes Lossy, keeps transparency, smallest of the lot, slowest to encode.
tiff .tiff yes yes Lossless, uncompressed-ish, for print and archival.
gif .gif yes no First frame only.
bmp .bmp yes no Decoded natively.
ico .ico yes no Decoded natively.
tga .tga yes no Decoded natively.
pnm .pnm yes no Decoded natively.
heic .heic macOS no Decoded through sips, then converted as usual.
heif .heif macOS no Decoded through sips, then converted as usual.
psd .psd macOS no Decoded through sips, then converted as usual.
pdf .pdf macOS no Decoded through sips, then converted as usual.
camera raw .dng .cr2 .nef … macOS no Decoded through sips, then converted as usual.

There is no SVG output. Vectorizing a raster image is a different problem, and the result is never the original vector.

Automation

imgx is safe to call from a script or an agent: it never prompts, never opens a pager, and never needs a TTY.

  • One line per file on stdout: status source -> destination WxH size, where status is ok, skip, plan or fail.
  • Failures go to stderr with the reason, so stdout stays parseable.
  • Exit 0 when every file converted or was skipped, 1 when anything failed or the arguments were rejected.
  • Re-running is idempotent: existing outputs are skipped, so a retry after a partial failure only redoes the unfinished work.

The status is left-padded to four characters, so split on whitespace rather than on fixed offsets.

Shell completion

zsh only, for now. The completion knows the five formats, every flag, and only offers files imgx can actually read. Homebrew installs it into share/zsh/site-functions, which is already on $fpath.

TypedSuggests
imgx <TAB>only svg png jpg jpeg webp avif tif tiff gif bmp ico tga heic heif psd pdf, not every file in the directory
imgx a.svg -f <TAB>png jpeg webp avif tiff
imgx a.svg --<TAB>every flag with its one-line description
imgx a.svg --background <TAB>white black grey gray red green blue
imgx a.svg -o <TAB>files and directories, since -o accepts either

Numeric flags (-w, --height, -q, -s) deliberately complete nothing. There is no useful set of widths to guess at.
